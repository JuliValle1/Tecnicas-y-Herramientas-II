# Módulo 1: Toma de Decisiones

## Selección y Evaluación de Factibilidad del Trabajo Final de Carrera mediante Gemini Notebook

### Descripción del Proyecto

Este repositorio contiene el Trabajo Práctico Nº1 correspondiente al Módulo 1: Toma de decisiones de la materia Trabajo Final de Carrera (Ingeniería Industrial, 2026). El objetivo principal del trabajo consistió en utilizar Gemini Notebook como un entorno de investigación interactivo para analizar, sintetizar y comparar tres propuestas temáticas preseleccionadas para el proyecto final académico. Esto permitió tomar una decisión fundamentada en datos, evidencia científica y alineación vocacional del equipo.

### Temas Evaluados

Durante el proceso de investigación se contrastaron tres líneas de trabajo:

* **TEMA A:** Producción de Aceite de Semillas de Uva a partir del aprovechamiento de subproductos vitivinícolas.
* **TEMA B:** Desarrollo de Bioplásticos Agroindustriales.
* **TEMA C:** Reciclaje y Valorización de Plásticos PET/PE.

### Decisión Final: Tema A (Puntaje: 9.20)

Tras evaluar la disponibilidad de información, la viabilidad técnica, el aporte de ingeniería y la alineación vocacional del grupo, el equipo seleccionó el **Tema A** (Producción de Aceite de Semillas de Uva) como opción definitiva para el Trabajo Final de Carrera.
